# Bienvenido a DM Hub Docs

¡Hola! Esta es la documentación oficial de **DM Hub (Distributors Marketplace Hub)**. Aquí encontrarás guías operativas sobre cómo configurar y utilizar las capacidades de la plataforma.

## 🚀 Características Clave

* **Constructor Visual:** Diseña tu tienda storefront personalizada sin código.
* **Control de Inventarios:** Administra el stock físico de tus productos por sucursal.
* **Flujo Kanban:** Gestiona reservaciones, valida pagos y realiza despachos en tiempo real.
* **Integraciones:** Conecta Stripe para pasarelas de pago, Cloudinary para imágenes y SMTP para correos automáticos.

## 👥 Roles Definidos

* **Administrador / Super Admin:** Control completo de configuraciones, tiendas, sucursales e integraciones.
* **Cajero:** Operación diaria de pedidos, cobros y despachos en el tablero Kanban.
* **Cliente:** Navegación pública, carrito de compras y creación de reservaciones.
